Causality and stability

Reading memory, causality and BIBO stability straight off the impulse response.

1 past question on this topic

Causality: no time travel

A system is causal if its output at any time depends only on the input at the present and past, never the future. Every physical system that runs in real time is causal: a speaker cannot react to a sound before it is played.

Reading causality from h(t)h(t)h(t)

The impulse response h(t)h(t)h(t) shows what the system does after we poke it with δ(t)\delta(t)δ(t) at t=0t=0t=0. If anything happens before t=0t=0t=0, the effect came before the cause.

Test for LTI systems:

causal  ⟺  h(t)=0  for all t<0causal  ⟺  h[n]=0  for all n<0.\text{causal}\iff h(t)=0\ \text{ for all } t<0\qquad\qquad \text{causal}\iff h[n]=0\ \text{ for all } n<0 .causal⟺h(t)=0  for all t<0causal⟺h[n]=0  for all n<0.

Why: y(t)=∫h(τ)x(t−τ) dτy(t)=\int h(\tau)x(t-\tau)\,d\tauy(t)=∫h(τ)x(t−τ)dτ. The input is used at times t−τt-\taut−τ; these are in the future exactly when τ<0\tau<0τ<0. If h(τ)=0h(\tau)=0h(τ)=0 for every τ<0\tau<0τ<0, no future value is ever used.

Systems that process stored data (images, recorded audio) are allowed to be non-causal: the whole signal is already available.

Stability: bounded in, bounded out

A system is BIBO stable (bounded-input, bounded-output) if every bounded input produces a bounded output. If ∣x(t)∣≤B|x(t)|\le B∣x(t)∣≤B always, the output must not shoot up to infinity.

Stability depends on the size of hhh

Write the convolution with hhh first (we may, since convolution commutes):

y(t)=∫−∞∞h(τ) x(t−τ) dτ.y(t)=\int_{-\infty}^{\infty}h(\tau)\,x(t-\tau)\,d\tau .y(t)=∫−∞∞​h(τ)x(t−τ)dτ.

If ∣x(t)∣≤B|x(t)|\le B∣x(t)∣≤B for all ttt, then ∣x(t−τ)∣≤B|x(t-\tau)|\le B∣x(t−τ)∣≤B too, and

∣y(t)∣≤∫−∞∞∣h(τ)∣ ∣x(t−τ)∣ dτ≤B∫−∞∞∣h(τ)∣ dτ.|y(t)|\le\int_{-\infty}^{\infty}|h(\tau)|\,|x(t-\tau)|\,d\tau\le B\int_{-\infty}^{\infty}|h(\tau)|\,d\tau .∣y(t)∣≤∫−∞∞​∣h(τ)∣∣x(t−τ)∣dτ≤B∫−∞∞​∣h(τ)∣dτ.

Two little problems: can h(t)h(t)h(t) be periodic?

1. If the system is causal, can h(t)h(t)h(t) be periodic? Suppose hhh is periodic with period TTT and h(t0)≠0h(t_0)\neq0h(t0​)=0 for some t0>0t_0>0t0​>0. Then the same value repeats backwards:

h(t0)=h(t0−T)=h(t0−2T)=⋯\begin{aligned}&h(t_0)\\[6pt]&= h(t_0-T)\\[6pt]&= h(t_0-2T)\\[6pt]&= \cdots\end{aligned}​h(t0​)=h(t0​−T)=h(t0​−2T)=⋯​

2. If the system is stable, can h(t)h(t)h(t) be periodic? A non-zero periodic hhh has some positive area AAA of ∣h∣|h|∣h∣ in each period. Over infinitely many periods,

∫−∞∞∣h(t)∣ dt=A+A+A+⋯=∞.\begin{aligned}&\int_{-\infty}^{\infty}|h(t)|\,dt\\[6pt]&= A+A+A+\cdots\\[6pt]&= \infty .\end{aligned}​∫−∞∞​∣h(t)∣dt=A+A+A+⋯=∞.​

Problem: how much delay makes it causal?

Exam pointers

  • Decide causality and stability separately; all four combinations are possible.
  • For any u(c−t)u(c-t)u(c−t) or u(t+c)u(t+c)u(t+c) factor, first write down the support of hhh. That settles causality in one line.
  • For stability, actually evaluate ∫∣h∣\int|h|∫∣h∣ (or ∑∣h∣\sum|h|∑∣h∣) and quote the finite value.
