(i) Linear system. A system x→yx\to yx→y is linear if it obeys superposition:

  • Additivity: x1→y1, x2→y2 ⇒ x1+x2→y1+y2x_1\to y_1,\ x_2\to y_2\ \Rightarrow\ x_1+x_2\to y_1+y_2x1​→y1​, x2​→y2​ ⇒ x1​+x2​→y1​+y2​.
  • Homogeneity: x→y ⇒ ax→ayx\to y\ \Rightarrow\ a x\to a yx→y ⇒ ax→ay for any constant aaa.

Together: a1x1+a2x2 → a1y1+a2y2a_1x_1+a_2x_2\ \to\ a_1y_1+a_2y_2a1​x1​+a2​x2​ → a1​y1​+a2​y2​. Consequences:

  • zero input gives zero output;
  • the total response = zero-input response + zero-state response.

  • Test: compute the output for the shifted input, then shift the original output, and compare.
  • y(t)=x(t−1)y(t)=x(t-1)y(t)=x(t−1) and y=x2(t)y=x^2(t)y=x2(t) are time invariant.
